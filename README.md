# WordFlip

Готовое приложение для GitHub Pages. Открывается в браузере, работает офлайн, можно добавить на экран телефона как обычное приложение (иконка WordFlip).

## Как выложить на GitHub (один раз, 5 минут)

1. Зайдите на [github.com](https://github.com) и создайте новый репозиторий (кнопка **New repository**). Назовите его, например, `wordflip`. Сделайте его **Public**.
2. На странице репозитория нажмите **Add file → Upload files** и загрузите все файлы из этой папки:
   - `index.html`
   - `manifest.json`
   - `sw.js`
   - `icon-192.png`
   - `icon-512.png`
3. Нажмите **Commit changes**.
4. Зайдите в **Settings → Pages** репозитория.
5. В разделе **Source** выберите branch `main` и папку `/ (root)`, нажмите **Save**.
6. Через 1–2 минуты GitHub покажет ссылку вида:
   `https://ваш-логин.github.io/wordflip/`

## Как установить на телефон

**iPhone:** откройте ссылку в Safari → кнопка «Поделиться» → **«На экран „Домой“»**.

**Android:** откройте ссылку в Chrome → меню (три точки) → **«Добавить на главный экран»**.

После этого на экране появится иконка WordFlip, приложение будет открываться без браузерной строки и будет работать даже без интернета (после первого открытия).

## Локальная проверка без GitHub

Можно просто открыть `index.html` прямо в браузере на телефоне или компьютере — всё заработает, но добавление на главный экран и офлайн-кеш через `sw.js` корректно работают только когда файлы отданы через `http(s)` (например, с GitHub Pages), а не открыты как локальный файл.
